\# C# Algorithms Portfolio



Учебный проект на C# и .NET 8, демонстрирующий основные алгоритмы

сортировки, поиска и работы с графами.



\## Реализованные алгоритмы



\### Сортировка и поиск



\- QuickSort — быстрая сортировка.

\- MergeSort — сортировка слиянием.

\- BinarySearch — бинарный поиск в отсортированном массиве.



\### Алгоритмы на графах



\- BFS — поиск в ширину.

\- DFS — поиск в глубину.

\- Dijkstra — поиск кратчайших путей во взвешенном графе

&#x20; с неотрицательными весами.



\## Таблица сложности



| Алгоритм | Временная сложность | Дополнительная память |

|---|---|---|

| QuickSort | O(n log n) в среднем, O(n²) в худшем случае | O(n) на выходную копию; рекурсия зависит от глубины |

| MergeSort | O(n log n) | O(n) |

| BinarySearch | O(log n) | O(1) |

| BFS | O(V + E) | O(V) |

| DFS | O(V + E) | O(V) |

| Dijkstra | O((V + E) log V) | O(V) |



Здесь:

\- n — количество элементов массива;

\- V — количество вершин графа;

\- E — количество рёбер графа.
